# 3D Printing Simulator

**[Open the simulator](https://goodguy1963.github.io/3d-druck-simulator/)**

An interactive teaching tool that compares FFF/FDM, SLA resin and SLS powder-bed printing. Change layer height, model size, infill and quantity to see how print time, material use and cost change across three example parts.

- English is the default language; use the **DE** button to switch to German.
- Works on desktop, projectors and phones, including landscape mode.
- No installation or shared Wi-Fi required.

## Run locally

Open `index.html` in a browser. The simulator has no build step or external dependencies.
